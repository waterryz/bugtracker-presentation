# БагТрекер — моушн-презентация

Анимированная презентация локального приложения БагТрекер: 8 сцен, реальные экраны интерфейса, канбан и локальная база данных.

## Как открыть

Скачайте репозиторий через **Code → Download ZIP**, распакуйте и откройте `index.html` в Chrome. Установка зависимостей и запуск сервера не нужны. Все изображения встроены в файл.

## Управление

- **← / →** — предыдущий и следующий слайд.
- **Автопоказ** или **пробел** — автоматический показ / пауза.
- **F** — полный экран.
- **Home / End** — первый и последний слайд.
- Нажатие на шкалу — переход к выбранной сцене.
- На телефоне доступны свайпы.

Автопоказ длится 1 минуту 26 секунд. Презентация без звука и учитывает настройку уменьшения движения.

## О содержимом

Показаны демонстрационные данные и возможности персональной локальной версии. В Chrome приложение использует SQLite через IndexedDB. Данные между устройствами автоматически не синхронизируются. Этот репозиторий содержит презентацию; исходный код Flutter-приложения сюда не включён.
